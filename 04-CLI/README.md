# CLI

在 Linux 上，OmniStudio 不是独立 GUI 客户端，而是基于 OmniInfer 的：

- `./omniinfer` CLI
- 本地 Gateway
- 本地 OpenAI 兼容 API

## 阅读建议

第一次使用建议按这个顺序：

1. `概览`
2. `快速开始`
3. `后端与运行时`
4. `模型与量化`
5. `获取与加载`
6. `对话与多模态`
7. `性能优化`
8. `故障排查与 FAQ`

如果你要查看本地 API、Gateway 配置、开发集成或引擎说明，请继续阅读：

- [开发者文档](../03-开发者文档/README.md)
