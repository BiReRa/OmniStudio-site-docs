# 常见问答

## Linux 上为什么没有 GUI？

当前 OmniStudio Linux 形态以 CLI 和本地 Gateway 为主，这样更适合：

- 自动化
- 服务集成
- 开发和排障

## `./omniinfer` 会自动启动服务吗？

会。Linux、macOS、Windows 的桌面模式下，CLI 会在需要时自动拉起本地 Gateway。

## backend profile 是必须的吗？

不是。大多数情况下：

- 选 backend
- 加载模型
- 直接聊天

就够了。profile 只在你需要 backend-native 高级参数时更有价值。

## Linux 上推荐从哪个 backend 开始？

通常先从 `llama.cpp-linux` 开始。

## `GET /v1/models` 能用吗？

当前 OmniInfer 不维护它。请改用 `/health` 或 `/omni/state`。
