# OmniStudio 文档中心

OmniStudio 当前主要分为四类文档入口：

- **PC 客户端**
  面向 Windows 与 macOS 图形化客户端用户
- **Android 客户端**
  面向 Android 手机端用户（OmniChat）
- **Linux CLI**
  面向 Linux 下的 `./omniinfer`、Gateway 和终端使用流程
- **开发者文档**
  面向本地接入、接口调用、配置排查和引擎相关工作

## 选择你的入口

如果你使用的是 Windows / macOS 桌面客户端，请从：

- [PC 客户端](02-客户端/README.md)

如果你使用的是 Android 手机：

- [Android 客户端](05-Android客户端/README.md)

如果你使用的是 Linux CLI，请从：

- [Linux CLI](04-CLI/README.md)

如果你需要查看 API、配置、引擎或集成说明，请从：

- [开发者文档](03-开发者文档/README.md)

## 你会在这里看到什么

- 快速开始与基础操作
- 模型、后端与运行时说明
- 本地 API、配置与开发接入方式
- 性能优化、故障排查与常见问答

## 推荐阅读顺序

1. 先确认你要看的是哪个平台的文档
2. 从对应入口进入
3. 再继续阅读模型、接口、性能和排障章节
