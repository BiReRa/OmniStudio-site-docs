# OmniStudio 文档中心

这套文档由原始的 `OmniStudio网页文档框架.md` 拆分而来，目的是把原本偏“单页大纲”的内容整理成适合网页文档左侧目录导航的多文件结构。

## 文档分组

| 分组 | 说明 |
|------|------|
| 概览 | 介绍 OmniStudio 的定位、核心概念和系统要求 |
| 入门 | 面向网页端用户，说明界面布局、模型管理和聊天使用方式 |
| 对话 | 说明会话记录、状态流转、上下文机制和长对话建议 |
| 模型 | 介绍模型类型、模型家族、标签能力和详情信息 |
| 下载 | 说明模型下载流程、量化选择、状态管理和本地存储 |
| 开发者 | 提供 Gateway 启动、模型加载和首个请求示例 |
| 引擎 | 说明 OmniInfer 后端架构、`llama.cpp` 引擎和维护方式 |
| 设置 | 汇总 Gateway 常用配置、运行时参数和高级选项 |
| 性能 | 介绍吞吐、延迟、显存与内存需求，以及模型选择建议 |
| 故障排查 | 汇总启动、下载、加载、性能与 GPU 相关问题 |
| FAQ | 回答常见问题，并补充模型、量化和运行时选择建议 |
| API | 拆分控制平面 API 与推理 API，便于单独检索 |
| 支持 | 提供帮助入口、问题反馈方式与提单建议 |

## 使用建议

- 直接将 [SUMMARY.md](./SUMMARY.md) 作为左侧目录配置来源。
- 每个目录都对应一个一级菜单分组，便于后续接入静态站点生成器或自定义 Markdown 渲染器。
- 页面内容保留了原始框架的核心信息，并对部分标题做了中文化和归类整理。
