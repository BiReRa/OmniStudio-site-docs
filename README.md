# OmniStudio 文档中心

OmniStudio 当前主要分为三类文档入口：

- **客户端**
  面向 Windows 与 macOS 图形化客户端用户
- **开发者文档**
  面向本地接入、接口调用、配置排查和引擎相关工作
- **CLI**
  面向 Linux 下的 `./omniinfer`、Gateway 和终端使用流程

## 选择你的入口

如果你使用的是桌面客户端，请从：

- [客户端](02-客户端/README.md)

开始。

如果你需要查看 API、配置、引擎或集成说明，请从：

- [开发者文档](03-开发者文档/README.md)

开始。

如果你使用的是 Linux CLI，请从：

- [CLI](04-CLI/README.md)

开始。

## 你会在这里看到什么

- 快速开始与基础操作
- 模型、后端与运行时说明
- 本地 API、配置与开发接入方式
- 性能优化、故障排查与常见问答

## 推荐阅读顺序

1. 先确认你要看的是客户端、开发者文档还是 CLI
2. 从对应入口进入
3. 再继续阅读模型、接口、性能和排障章节
