# OmniStudio 文档中心

OmniStudio 当前有两条并行的使用形态：

- **Windows / macOS 客户端**
  以图形界面为主，适合桌面端交互式使用
- **Linux CLI**
  以 `./omniinfer` 和本地 Gateway 为主，适合终端、自动化和开发集成

## 选择你的平台

如果你使用的是桌面客户端，请从：

- [Windows 与 macOS 客户端](02-Windows与macOS客户端/README.md)

开始。

如果你使用的是 Linux CLI，请从：

- [Linux CLI](03-Linux-CLI/README.md)

开始。

- 模型、后端与运行时说明
- 本地 API 与开发接入方式
- 性能优化、故障排查与常见问答
