# Linux CLI

这一主线面向当前 Linux 平台的 OmniStudio 形态。

在 Linux 上，OmniStudio 不是独立 GUI 客户端，而是基于 OmniInfer 的：

- `./omniinfer` CLI
- 本地 Gateway
- 本地 OpenAI 兼容 API

## 这部分适合谁

- 直接在 Linux 终端中使用 OmniStudio / OmniInfer 的用户
- 需要把本地推理接入脚本、服务和工具链的开发者
- 需要定位 backend、模型和日志问题的运维人员

## 阅读建议

第一次使用建议按这个顺序：

1. `概览`
2. `快速开始`
3. `后端与运行时`
4. `模型与量化`
5. `获取与加载`
6. `对话与多模态`
7. `本地 API`
