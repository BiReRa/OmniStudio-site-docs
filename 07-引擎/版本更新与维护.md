# 版本更新与维护

## 更新引擎

更新 `llama.cpp` 引擎的标准流程如下：

1. 从 `llama.cpp` 官方仓库获取新版 `llama-server`。
2. 替换 `OmniInfer/platform/Windows/llama.cpp-CPU/bin/` 目录下的可执行文件。
3. 重启 Gateway，使新引擎生效。

也可以使用项目脚本自行编译：

```powershell
.\OmniInfer\platform\Windows\llama.cpp-CPU\scripts\build-llama-cpu.ps1
```

在更新前，建议先备份当前版本，以便出现兼容性问题时快速回退。

## 健康检查

```bash
curl http://127.0.0.1:9000/health
curl http://127.0.0.1:9000/omni/state
curl http://127.0.0.1:9000/omni/backends
```

`/health` 返回示例：

```json
{
  "status": "ok",
  "omni": {
    "backend": "llama.cpp(CPU)",
    "model": "Qwen2.5-7B-Q4_K_M.gguf",
    "mmproj": null,
    "backend_runtime": {
      "host": "127.0.0.1",
      "port": 18080,
      "running": true,
      "pid": 12345
    }
  }
}
```

## 维护建议

- 定期检查 Gateway 日志和后端日志
- 记录引擎升级前后的模型兼容性差异
- 在文档中明确保留“版本回退”说明
