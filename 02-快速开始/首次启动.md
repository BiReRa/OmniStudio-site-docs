# 首次启动

## 先看当前机器能用哪些 backend

```bash
./omniinfer backend list
```

这个命令会显示：

- backend 名称
- 是否被 CLI 选中
- 当前服务是否激活
- runtime 是否可用
- backend 能力标签

## 选择一个 backend

```bash
./omniinfer select llama.cpp-linux
```

选择后，CLI 会把结果保存在本地状态中，并自动为该 backend 创建一个高级配置模板：

- `~/.config/omniinfer/backend_profiles/<backend>.json`

## 查看状态

```bash
./omniinfer status
```

状态页会显示：

- 本地服务是否已运行
- 当前选中的 backend
- 当前是否已有模型加载
- 默认 thinking 状态
