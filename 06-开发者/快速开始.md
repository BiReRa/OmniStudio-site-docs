# 快速开始

这一页面向需要直接启动 Gateway、加载模型并发送首个请求的开发者。

## 环境准备

1. 安装 Python 3.8 或更高版本。
2. 确保系统满足最低硬件要求，建议至少 8GB RAM。

## 安装步骤

```bash
git clone https://github.com/omnimind-ai/OmniInfer.git
cd OmniInfer
pip install -r requirements.txt
```

Windows 平台通常已自带预编译 `llama-server`，位于：

```text
OmniInfer/platform/Windows/llama.cpp-CPU/bin/
```

macOS 和 Linux 用户需要自行编译 `llama-server`，或从 `llama.cpp` Releases 下载对应平台版本后放入合适目录。

## 启动 Gateway

```bash
python omniinfer_gateway.py
```

启动后可看到类似输出：

```text
OmniInfer Gateway listening on http://127.0.0.1:9000
Default backend: llama.cpp(CPU)
Managed backend target: llama.cpp(CPU) on http://127.0.0.1:18080
```

## 验证服务状态

```bash
curl http://127.0.0.1:9000/health
```

如果返回 `{"status": "ok", ...}`，说明 Gateway 已正常运行。

## 选择并加载模型

先查看可用模型：

```bash
curl http://127.0.0.1:9000/omni/models
```

再加载指定模型：

```bash
curl -X POST http://127.0.0.1:9000/omni/model/select \
  -H "Content-Type: application/json" \
  -d '{"model": "your-model-name.gguf"}'
```

对于 VLM，可以手动指定 `mmproj`：

```bash
curl -X POST http://127.0.0.1:9000/omni/model/select \
  -H "Content-Type: application/json" \
  -d '{"model": "your-vlm-model.gguf", "mmproj": "mmproj-F32.gguf"}'
```

## 发送第一个请求

```bash
curl -X POST http://127.0.0.1:9000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "messages": [{"role": "user", "content": "你好，请介绍一下你自己"}],
    "stream": false
  }'
```

如果需要流式输出，可将 `stream` 改为 `true`。
