# 响应与更新

## 响应格式

OmniStudio 返回兼容 OpenAI 风格的响应结构，示例如下：

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "你好！我是一个本地运行的 AI 助手..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 10,
    "completion_tokens": 50,
    "total_tokens": 60
  }
}
```

其中 `usage` 可用于统计 token 消耗和评估推理性能。

## 版本策略

OmniStudio 采用语义化版本号，格式为：

```text
主版本.次版本.修订号
```

## 更新方式

```bash
cd OmniInfer
git pull origin main
pip install -r requirements.txt --upgrade
```

## 版本信息查看建议

- GitHub `Releases` 页面适合展示版本更新说明
- 变更记录中建议突出新功能、Bug 修复、已知兼容性问题和引擎版本变动
- 对开发者文档而言，可以把这一页作为“运维与更新”入口页
