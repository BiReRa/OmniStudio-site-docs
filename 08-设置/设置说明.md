# 设置说明

OmniInfer Gateway 支持通过命令行参数和环境变量进行配置。

## 通用设置

| 参数 | 环境变量 | 默认值 | 说明 |
|------|---------|--------|------|
| `--host` | — | `127.0.0.1` | Gateway 绑定地址 |
| `--port` | — | `9000` | Gateway 绑定端口 |
| `--backend-host` | — | `127.0.0.1` | 后端引擎绑定地址 |
| `--backend-port` | — | `18080` | 后端引擎绑定端口 |
| `--llama-server-path` | `OMNIINFER_LLAMA_SERVER_PATH` | `platform/Windows/llama.cpp-CPU/bin/llama-server.exe` | `llama-server` 路径 |
| `--models-dir` | `OMNIINFER_MODELS_DIR` | `platform/Windows/llama.cpp-CPU/models/` | 模型目录 |
| `--startup-timeout` | — | `60` | 后端启动超时时间（秒） |

## 运行时设置

模型加载与推理时，常用参数包括：

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `n_ctx` | 上下文长度 | 模型默认值 |
| `n_gpu_layers` | GPU 卸载层数，`0` 表示纯 CPU | `0` |
| `n_threads` | CPU 推理线程数 | 系统核心数 |
| `temperature` | 生成温度 | `0.7` |
| `max_tokens` | 单次生成最大 token 数 | `1024` |
| `top_p` | 核采样阈值 | `0.9` |
| `top_k` | Top-K 采样 | `40` |

这些参数既可以放在 `/v1/chat/completions` 的请求体中，也可以作为 Gateway 默认配置管理。

## 更新设置

OmniStudio 的更新通常分为两部分：

- **Gateway 更新**：拉取最新 `omniinfer_gateway.py` 或主仓库代码
- **引擎更新**：替换 `bin/` 下的 `llama-server`

当前版本不强调自动更新，因此文档中建议明确手动更新方式。

## 高级设置

| 配置项 | 说明 |
|--------|------|
| `OMNIINFER_LLAMA_SERVER_PATH` | 自定义 `llama-server` 路径 |
| `OMNIINFER_MODELS_DIR` | 自定义模型目录 |
| `--backend-host` / `--backend-port` | 自定义后端地址与端口 |
| `--startup-timeout` | 大模型场景下调整后端启动超时 |

如需将服务暴露给局域网内其他设备访问，可设置：

```bash
python omniinfer_gateway.py --host 0.0.0.0
```

仅建议在可信网络环境中启用此配置。
