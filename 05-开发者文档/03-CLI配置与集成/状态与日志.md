# 状态与日志

## CLI 状态文件

CLI 会在本地保存状态，常见位置包括：

```text
~/.config/omniinfer/cli_state.json
```

这里通常会记录当前选中的 backend。

## Gateway 日志

CLI 自动拉起的 Gateway 日志通常写到：

```text
~/.cache/omniinfer/gateway.log
```

## Runtime 日志

每个 backend 自己的日志通常位于对应 runtime 目录下：

```text
.local/runtime/linux/<backend>/logs/
```

或发布包中的：

```text
runtime/<backend>/logs/
```

## 状态查询

```bash
./omniinfer status
curl -s http://127.0.0.1:9000/health
curl -s http://127.0.0.1:9000/omni/state
```

排障时，这三个入口通常最有用。
