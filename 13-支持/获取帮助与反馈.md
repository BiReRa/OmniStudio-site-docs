# 获取帮助与反馈

## 获取帮助

- GitHub Issues: [OmniInfer Issues](https://github.com/omnimind-ai/OmniInfer/issues)
- 贡献说明: [Contributing to OmniInfer](https://github.com/omnimind-ai/OmniInfer/blob/main/CONTRIBUTING.md)

## 如何报告问题

提交问题时，建议至少包含以下信息：

- 操作系统和版本
- OmniStudio / Gateway 版本
- 使用的模型名称与量化格式
- 问题描述与复现步骤
- Gateway 控制台错误日志
- `/health` 接口返回内容

## 分享反馈

你可以通过以下方式提供建议和反馈：

- 在 GitHub Discussions 中发起讨论
- 通过 GitHub Issues 提交功能建议，并标注 `enhancement`
- 参与代码贡献或文档贡献

## 作为菜单栏目时的建议命名

如果网页左侧目录希望更贴近中文用户习惯，这一页可以直接命名为：

- 获取帮助
- 问题反馈
- 社区与贡献
