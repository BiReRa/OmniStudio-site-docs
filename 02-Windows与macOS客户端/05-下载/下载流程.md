# 下载流程

## 标准下载流程

模型下载流程建议拆成固定的五步，便于网页端文档和产品界面保持一致：

1. 进入模型下载页面，浏览可用模型列表。
2. 点击目标模型卡片，查看详情与可用量化版本。
3. 选择合适的量化格式，通常推荐 `Q4_K_M`。
4. 点击下载或安装按钮，开始拉取模型文件。
5. 下载完成后，模型会自动出现在“已下载”列表中，可直接加载使用。

## 开始下载后会发生什么

在模型下载页面选择目标模型和量化版本后，点击安装按钮即可开始下载。下载过程中：

- 模型文件会保存到本地模型目录
- 页面会显示下载进度和已下载大小
- 若模型为 VLM，系统还会同时下载对应的 `mmproj` 文件

## 默认模型目录

源码仓库模式下，Windows 默认模型目录示例：

```text
.local/runtime/windows/llama.cpp-cpu/models/
```

如果你使用的是打包版本，则更常见的是：

```text
runtime/llama.cpp-cpu/models/
```

如果后续页面还要继续扩展，可以把“下载流程”单独作为左侧菜单中的核心入口页。
