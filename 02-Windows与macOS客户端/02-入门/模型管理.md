# 模型管理

## 管理入口

![模型选择菜单](../../assets/omnistudio-model-selector.jpg)

OmniStudio 将模型管理入口放在高频操作区域，用户可以在聊天过程中随时进入模型下载、筛选和切换流程。

## 页面结构

模型管理区域主要由四部分组成：

- **模型选择弹窗**：点击顶部模型名称，弹出所有可用模型列表。
- **顶部标签页**：通过“下载模型”和“已下载”分离远端可获取资源与本地已安装资源。
- **模型筛选与列表区**：支持按模型厂商、模型特性、视觉模型等条件筛选。
- **详情与操作区**：展示模型格式、能力标签、更新时间、下载次数与可选量化版本。

## 典型操作

### 切换模型

点击模型名称后，会看到已安装模型列表，例如 `Qwen 3.5-4B`、`Qwen 3.5-0.8B`、`Qwen 3.5-9B`。选中后系统会卸载当前模型并加载新模型。

### 下载模型

在详情面板中选择合适的量化版本后，点击下载按钮即可一键安装。下载完成后模型会自动进入“已下载”列表。

### 筛选模型

筛选区适合配合左侧目录或标签系统使用，可按以下维度缩小范围：

- 模型家族，例如 `Qwen`
- 模型特性，例如“视觉模型”“深度思考”
- 资源偏好，例如轻量模型或推荐模型
