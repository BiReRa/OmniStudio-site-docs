# 模型详情与卡片

## 模型详情面板

在模型下载页面点击任意模型卡片后，可以查看更完整的详情信息，通常包括：

- **模型描述**：概括模型的用途和特点
- **参数规模**：例如 `0.8B`、`4B`、`9B`
- **可用量化版本**：如 `Q4_K_M`、`Q5_K_M`
- **系统要求**：运行该模型的最低配置与推荐配置
- **下载按钮**：确认量化版本后执行安装

## Model Card / README 的价值

每个模型在 HuggingFace 等平台上一般都会附带 Model Card 或 README。下载前建议顺手查看：

- 模型架构与训练信息
- 使用许可证
- 评测基准
- 推荐 Prompt 格式与 Chat Template

## 下载前建议确认

下载前，建议重点确认：

- 这个模型适不适合自己的硬件
- 是否支持所需语言或多模态能力
- 推荐选择哪种量化版本
