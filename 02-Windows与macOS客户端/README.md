# Windows 与 macOS 客户端

这一主线面向图形化客户端用户。

这里保留了 Windows 与 macOS 客户端的界面、模型下载、聊天交互和桌面使用体验说明，同时把和当前 OmniInfer 实现强绑定的路径、API 和运行时行为更新到了新的口径。

## 这部分适合谁

- 使用桌面客户端的最终用户
- 需要为客户端编写帮助中心或产品介绍的人
- 需要理解客户端背后 Gateway / runtime 行为的开发者
