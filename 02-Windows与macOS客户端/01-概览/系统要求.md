# 系统要求

## 平台最低要求

| 平台 | 最低要求 |
|------|---------|
| **Windows** | Windows 10 及以上，`x86_64` 架构 |
| **macOS** | macOS 12 及以上，支持 Intel 与 Apple Silicon |
| **Linux** | 主流发行版，`x86_64` 架构 |
| **Android** | Android 10 及以上 |
| **iOS** | iOS 15 及以上 |

## 通用运行要求

- Python 3.8 及以上，用于运行 Gateway。
- 至少 8GB RAM，推荐 16GB 及以上。
- 预留足够的磁盘空间存放模型文件，GGUF 模型常见体积约为 2GB 到 30GB。

## 建议配置

| 使用场景 | 建议配置 |
|------|------|
| 轻量体验 | 8GB RAM，1B 到 3B 模型 |
| 日常使用 | 16GB RAM，7B 到 8B 模型 |
| 高质量生成 | 32GB 及以上 RAM，13B 以上模型 |

如果计划运行视觉模型、多轮长上下文会话或大参数量模型，建议同时关注内存、显存与磁盘空间的总和，而不是只看 CPU 或 GPU 单项指标。
