# 规划中的后端

以下后端仍然可以在产品规划和架构视角中保留，但应与当前 Linux 已落地能力区分开来：

| 后端 | 说明 | 当前文档定位 |
|------|------|--------------|
| `OmniInfer Native` | 自研引擎 | 规划 / 演进方向 |
| `vLLM` | 高吞吐推理引擎 | 规划 / 演进方向 |
| `MNN` | 移动端推理框架 | 规划 / 平台扩展 |
| `MLX` | Apple Silicon 原生引擎 | 跨平台规划 |
| `ET (ExecuTorch)` | 边缘端推理方向 | 规划 |

## 文档写法建议

- 可以保留这些名称，帮助读者理解整体路线
- 但不要把它们和当前 Linux CLI 已稳定可用能力混写
- 具体操作页仍应以当前 OmniInfer 实现为准
